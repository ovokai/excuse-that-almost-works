The entry is a single line of plain text — `so sorry, water heater's leaking into the downstairs unit, plumber's here, can't leave till it's fixed` — written for GTA 6 launch week. It wins on restraint: no dead relatives, no dramatic illness, just a boring, specific apartment emergency with a plumber already on site and a reason the sender genuinely cannot leave.

## Run it

```sh
node main.ts
```
